Web Technology

HTML

What is HTML? HTML stands for Hyper Text Markup Lanauge, it is a markup language that describes the structure of a website. The markup language tells the computing device what to display. HTML isn't programming language but rather markup language.

CSS

What is CSS? CSS stands for Cascading Style Sheets. Unlike HTML, CSS is a style sheet language. The main fuction of CSS is to indicate how HTML elements would look on screen, so it is a more visual for the audience.

JavaScript

What is JavaSCript? JavaScript, short for JS, is a high level programming language that is one of the three most important language along with HTML and CSS in the World Wide Web. The engine. JS enables updating content, controls multimedia, animates images, and processes complex logic through high level codings.

Bootstrap

What is Bootstrap? Booststrap is a free and open-source front-end framework used by web developers and programmers to build accessible, mobile-first websites and applications quickly. The website is made designed for primarily mobile websites.
